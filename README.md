# 场景B · 安心药箱 v2

第一版核心：明确服药指引 → 父母本人确认 → 子女确认消息 → 未确认时升级联系。

交付：product.html 产品说明；网页Demo与源码；review.html 验证复盘。

## 运行

Node.js 18+，无需安装依赖。双击启动Demo.bat，或执行 node server.js（默认8776）。本次已运行的新版地址：http://127.0.0.1:8788/ 。运行其他端口可在PowerShell设置 `$env:PORT='8788'` 后执行 `node server.js`；已有服务时直接打开。

## 正常演示

载入新版家庭样例 → 父母允许分享 → 推进1分钟，到08:00 → 查看亮灯、外观、位置、剂量与吃法 → 试取错药格 → 打开对应药格 → 本人确认已按提示服药 → 子女端查看短信Mock及依据。

## 异常演示

重新载入样例并授权 → 推进1分钟 → 推进15分钟（再次提醒）→ 再推进15分钟（达到30分钟）→ 子女收到未确认短信Mock → 模拟电话联系并备注。也可将窗口设为60分钟，或父母选择找不到药、记不清、需要电话核对，或模拟设备离线。

## 配置与能力边界

“提前准备”可输入已有安排，用规则Mock提取药名、剂量与时刻，补齐位置、外观、吃法与核对人，确认后启用。可上传PNG/JPEG/WebP实物参考照片（最大1MB，仅本机）；不自动识别药品。

默认提取、指引与摘要均为Mock。提取仍可通过服务端环境变量AI_BASE_URL、AI_MODEL、AI_API_KEY配置兼容接口，真实模型未验证。密钥留环境中，不放源码。

时钟为按钮推进的演示时钟；关闭页面后不会持续提醒。短提示音与朗读依赖浏览器支持。药格亮灯、短信和电话不接真实服务。双端同一浏览器模拟，无云端或真实身份权限，不用于真实医疗决策。
