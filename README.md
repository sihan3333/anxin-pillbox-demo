# 场景B · 安心药箱 v3

第一版核心：到点提醒父母吃什么、在哪、怎么吃 → 父母一键确认 → 子女收到通知 → 没确认或父母求助时，才需要子女打电话。

交付：product.html 产品说明；网页 Demo 与源码；review.html 验证复盘。

## 在线访问

https://sihan3333.github.io/anxin-pillbox-demo/ （纯静态，无需安装）

## 怎么体验

页面上并排两部手机：左边是妈妈的，右边是你（女儿）的。顶部选一个情景，黄色提示框会一步步告诉你点哪里，要点的按钮会闪烁。

1. **妈妈按时吃药**：到点响铃 + 语音 → 接听看到药盒样子、亮灯药格、剂量和吃法（语音朗读，并提示遇到问题按橙色求助）→ 我吃好了 → 语音再确认 → 子女手机收到通知 → AI 帮我分析（今天情况、一周规律、可一键执行的建议）。
2. **妈妈忘了吃药**：08:00 没接 → 08:15 第 2 次提醒 → 08:30 子女收到提醒 → 打电话（或发短信）→ 妈妈说还没吃 → 15 分钟后药箱再响铃 → 妈妈确认。
3. **妈妈找不到药**：接听 → 我需要帮忙 → 带序号并语音朗读的 4 个选项 → 子女立刻收到求助 → 打电话。
4. **帮妈妈录入新药**：子女语音说出或粘贴用法 → AI 填好药名、剂量、时间、吃法（没说清的不猜）→ 上传药盒照片或选颜色形状 → 保存 → 到点妈妈手机按此提醒。

妈妈端每个页面都有语音播报和"再听一遍"。语音输入依赖浏览器支持，不支持时自动用示例语句代替。

还有"自由体验"模式，可以自己推进时间。等待多久通知子女（30/60 分钟）在子女手机"药品"页设置。

## AI 在哪里参与

- 录入：把医嘱/药盒文字整理成药名、剂量、时间、吃法草稿（规则 Mock），原文没写的不猜，由子女补全核对。
- 提醒：把结构化安排转成老人听得懂的口语指引，并用浏览器语音朗读。
- 小结：汇总当天确认、超时与求助情况，给子女是否需要打电话的建议和开场白（规则 Mock）。

响铃、再次提醒、超时通知和服药状态由固定规则控制，AI 不决定吃什么药，也不判断是否真的吃了。

## 边界

药品为虚构示例；响铃、短信、电话、药格亮灯都在网页内模拟；演示时间由按钮推进。"已吃"是本人或电话确认的记录，不能证明实际吞服。
