# 安心药箱

第一版核心：到点提醒父母吃什么、在哪、怎么吃 → 吃前可以拍一下药盒，核对拿没拿对 → 父母一键确认 → 子女收到通知 → 没确认、拿错药或父母记不清时，才需要子女打电话。

交付：`prd.html` PRD；`product.html` 产品说明；网页 Demo 与源码；`review.html` 测试与设计决策；`strategy.html` 竞品、商业模式与 MVP 取舍；`research.html` 用户验证计划；`figma-prototype/` Figma 高保真原型 v3（父母端 11 屏 + 子女端 10 屏 + 状态规范板 + 成功指标板）。

## 怎么体验

页面上并排两部手机：左边是妈妈的，右边是你（女儿）的。顶部选一个情景，黄色提示框会一步步告诉你点哪里，要点的按钮会闪烁。建议打开电脑声音。

1. **妈妈按时吃药**：到点响铃 + 语音 → 接听看到药盒样子、要打开的格子、剂量和吃法，同一时刻几种药按"饭前 → 和饭一起 → 饭后 → 睡前"排好顺序读出 → 我吃好了 → 语音再确认 → 子女手机马上收到通知 → 看看这一周的规律和建议。
2. **妈妈忘了吃药**：08:00 没接 → 08:15 第 2 次提醒 → 08:30 子女收到"还没确认" → 打电话 → 妈妈说还没吃 → 15 分钟后妈妈手机再响铃 → 妈妈确认。
3. **妈妈记不清吃没吃**：接听 → 我需要帮忙 → 带序号并语音朗读的选项 → 选"记不清吃没吃" → 妈妈端提醒"先不要再吃这一次的药" → 子女立刻收到求助，并提示先看药盒格子 → 电话核对。
4. **现在不方便吃**：降糖药要和饭一起吃，饭还没好 → 选"还没开饭" → 20 分钟后再响铃，不算没确认 → 看完指引忘了按确认，10 分钟后手机追问一句"吃好了吗"。
5. **拍照发现拿错药**：吃之前点"拍一下，看拿对没有" → 拿了别的药盒，手机说"这盒药不在清单里，先别吃"，子女同时收到提醒 → 换成对的药盒，手机说"对了" → 子女的今日安排里记着核对结果。没有真药盒也能用页面里的 4 个示例药盒试。

"自由体验"里可以自己推进时间，也可以在子女手机"药品"页试试录入新药（打字或语音说出用法）。

## MVP（人工模拟版）

https://sihan3333.github.io/anxin-pillbox-demo/mvp/

上面的 Demo 是可交互原型。`mvp/` 是给真实家庭跑 3 天用的人工模拟版 MVP：提醒用手机闹钟，父母打开专属链接看这一顿吃什么并确认，确认通过短信发给子女，"超时通知"由子女按规则人工完成。包含测试指南（事先定好的成功标准、每天规则、访谈问题）、子女设置页、父母页和自动汇总的记录页。纯前端，药品信息只放在家人之间传递的链接里，不上传。

## AI 在哪里参与

- 录入：把子女说的话或医嘱文字整理成药名、剂量、时间、吃法草稿。由 DeepSeek（经 Cloudflare Worker 中转）抽取，并要求每个字段给出原文依据；规则层逐项核对，依据不在原话里、剂量数字对不上、或时刻是从「一日三次」「早晚」推出来的，一律去掉，留给子女补全。没连上大模型时用规则整理兜底。评测见 `eval/`：评测集 v2 共 120 条（seed / dev / holdout），全对 118/120、编造 0/191，详见 `eval/report.html` 和 `eval/DATASET.md`。
- 拍一拍核对：父母吃药前拍一下药盒。通义千问 qwen3-vl-plus（经同一个 Worker 中转）只把药盒上的通用名和规格抄下来，看不清的字写 □，并报告拿不准、药盒在照片里的位置；对不对由规则拿清单比对：名字和规格都对上才说"对了"，拿不准、有字被挡住、药盒离得太远一律说"看不清"，绝不猜。拿错药或拿到清单外的药，提醒父母先别吃并通知子女。子女登记药品时拍药盒，也用同一个接口预填药盒名和规格。评测见 `eval/photo/`：158 张仿真药盒图、14 类情况，误判"对了"由 5/107 降到 0/107，详见 `eval/photo/REPORT.md`。评测图全部为程序生成，还需要用真实药盒照片复测。
- 吃药指引：把结构化安排转成老人听得懂的口语，按吃法排好先后，并用浏览器语音朗读。
- "这一周的情况"是**规则统计**，不是大模型：从 7 天记录算出规律（如"周末早上要再提醒"）和建议。真实产品中，大模型可以负责把记录写成好懂的话、起草打电话的开场白。

响铃、再次提醒、超时通知和服药状态由固定规则控制，AI 不决定吃什么药，也不判断是否真的吃了。拍照核对只是提示，不改服药状态，父母不拍照也能照常确认。

## 边界

药品为虚构示例；响铃、短信、电话都在网页内模拟；演示时间由按钮推进。示例药盒是程序画的仿真图；拍照核对的照片只用于这一次识别，不保存。识图接口没连上时，示例药盒按图上印的字演示，页面会写明。"已吃"是本人或电话确认的记录，不能证明实际吞服。

## 运行与测试

- 直接双击 `index.html`，或打开上面的在线链接。
- 也可以安装 Node.js 18+ 后双击 `启动Demo.bat`（或运行 `node server.js`），浏览器打开 http://127.0.0.1:8776 。
- AI 中转：`worker/worker.js`，在 `worker/` 下运行 `npx wrangler deploy` 部署；密钥只存在 Cloudflare 后台。
- 测试：`npm test`（`tests/demo-check.js` 测试 Demo 的提醒、通知、求助、服药顺序、规则统计和拍照核对规则；`tests/mvp-check.js` 测试 MVP 的链接编码、服药顺序、该显示哪一顿和短信内容）。
