# 场景B · 安心药箱

第一版核心：到点提醒父母吃什么、在哪、怎么吃 → 父母一键确认 → 子女收到通知 → 没确认或父母记不清时，才需要子女打电话。

交付：`product.html` 产品说明；网页 Demo 与源码；`review.html` 验证与复盘。

## 在线访问

https://sihan3333.github.io/anxin-pillbox-demo/ （纯静态，无需安装）

## 怎么体验

页面上并排两部手机：左边是妈妈的，右边是你（女儿）的。顶部选一个情景，黄色提示框会一步步告诉你点哪里，要点的按钮会闪烁。建议打开电脑声音。

1. **妈妈按时吃药**：到点响铃 + 语音 → 接听看到药盒样子、亮灯药格、剂量和吃法，同一时刻几种药按"饭前 → 和饭一起 → 饭后 → 睡前"排好顺序读出 → 我吃好了 → 语音再确认 → 子女手机马上收到通知 → 看看这一周的规律和建议。
2. **妈妈忘了吃药**：08:00 没接 → 08:15 第 2 次提醒 → 08:30 子女收到"还没确认" → 打电话 → 妈妈说还没吃 → 15 分钟后药箱再响铃 → 妈妈确认。
3. **妈妈记不清吃没吃**：接听 → 我需要帮忙 → 带序号并语音朗读的选项 → 选"记不清吃没吃" → 妈妈端提醒"先不要再吃这一次的药" → 子女立刻收到求助，并提示先看药格 → 电话核对。

"自由体验"里可以自己推进时间，也可以在子女手机"药品"页试试录入新药（打字或语音说出用法）。

## AI 在哪里参与

- 录入：把子女说的话或医嘱文字整理成药名、剂量、时间、吃法草稿，原文没写的不猜，由子女补全核对。演示版用规则模拟。
- 吃药指引：把结构化安排转成老人听得懂的口语，按吃法排好先后，并用浏览器语音朗读。
- "这一周的情况"是**规则统计**，不是大模型：从 7 天记录算出规律（如"周末早上要再提醒"）和建议。真实产品中，大模型可以负责把记录写成好懂的话、起草打电话的开场白。

响铃、再次提醒、超时通知和服药状态由固定规则控制，AI 不决定吃什么药，也不判断是否真的吃了。

## 边界

药品为虚构示例；响铃、短信、电话、药格亮灯都在网页内模拟；演示时间由按钮推进。"已吃"是本人或电话确认的记录，不能证明实际吞服。

## 运行与测试

- 直接双击 `index.html`，或打开上面的在线链接。
- 也可以安装 Node.js 18+ 后双击 `启动Demo.bat`（或运行 `node server.js`），浏览器打开 http://127.0.0.1:8776 。
- 测试：`npm test`（`tests/demo-check.js`，测试 Demo 的提醒、通知、求助、服药顺序和规则统计）。
