# 安心药箱原型 · Figma 插件使用说明

当前是 v3。视觉参考主流开源移动端设计规范：品牌蓝 #0052D9、浅色标签、白卡片轻阴影、单元格列表、底部标签栏。

运行一次，会新建一页「安心药箱 原型 v3」（不会覆盖 v1、v2）。再次运行时，会先删掉上一次生成的「安心药箱 原型 v3」页面和 v3 的样式、颜色变量，再重新生成，不会留下重复的一套：

## 父母端 · 9 屏（适老化：大字、语音、一页一个决定）
1. 到点提醒：像来电一样响铃，写明要打开药盒哪几格
2. 吃药指引：按饭前 → 随餐 → 饭后 → 睡前排序；提示“也可以直接说‘吃好了’”
3. 再确认一次
4. 我需要帮忙：4 个带序号的选项
5. 记不清吃没吃：先别再吃
6. **新** 手机追问：看完指引还没确认时，手机主动问“吃好了吗”，说一声就能确认（降低忘按造成的误报）
7. **新** 第一次使用：父母本人同意分享，写清楚分享什么、不分享什么
8. **新** 每周装药：逐格显示、逐格朗读，装完拍照给子女
9. **新** 现在不方便吃：从①的“现在不方便吃？”进入，可选“还没开饭”（20 分钟后再提醒）或“我不在家”（30 分钟 / 1 小时 / 2 小时后再提醒）；子女端只显示“妈妈说待会再吃”

## 子女端 · 9 屏
1. 今天：状态写明来源（自己确认 / 电话确认），新增余量提醒和设置入口
2. 还没确认：写“还没确认”而不是“没吃”，先给打电话按钮
3. 妈妈求助：记不清时先请妈妈看药盒格子里的药还在不在
4. 录入新药：AI 提取的内容用蓝字标出原话来源，新增拍药盒或处方入口
5. 这一周：按确认来源统计（自己确认 / 第 2 次提醒后 / 电话确认 / 求助）
6. **新** 妈妈手机离线：手机故障和“没吃”分开，提示子女直接打电话
7. **新** 装药核对：照片 + 逐格清单，AI 比对仅供参考；余量提醒
8. **新** 提醒设置：等待 30/60 分钟、按顺序通知家人、每晚汇总、夜间免打扰
9. **新** 第一次使用：绑定妈妈的手机 → 邀请家人 → 妈妈同意

## 规范与指标
- 服药状态体系：6 种状态：自己确认、电话确认、待会再吃、求助中、还没确认、手机离线，分别写明怎么显示、什么时候出现、子女该做什么、会不会通知
- 成功指标：北极星、过程、护栏指标，目标值均为待试用验证的假设

每个画板下方都有一段“设计说明”，讲清楚这样设计的理由。

## 点击演示（右上角 ▶ 旁边的小箭头选流程）
- ① 按时吃药 / ③ 记不清：从父母端“到点提醒”开始
- ② 忘了吃药：从子女端“还没确认”开始
- ④ 妈妈手机离线
- ⑤ 每周装药：父母装药 → 拍照 → 子女核对
- ⑥ 第一次使用：子女开通 → 父母同意 → 子女首页
- 子女端首页：底部标签栏和右上角设置都能点

## 运行步骤（需要 Figma 桌面版）
1. 左上角 Figma 图标 → Plugins → Development → **安心药箱原型**。
2. 第一次使用时才需要 Import plugin from manifest…，选这个文件夹里的 `manifest.json`。
3. 如果右下角提示「生成失败：……」，把提示发给 Claude 修改。

药品、时间、家人和一周记录都是虚构示例。药盒照片是占位，可以在 Figma 里换成实拍。
