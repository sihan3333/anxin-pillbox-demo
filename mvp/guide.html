安心药箱 MVP · 3 天测试指南

人工模拟版 MVP：提醒用手机闹钟，确认用短信，"超时通知子女"由你按规则人工完成。目的是在写更多代码之前，先用真实家庭验证最关键的假设。

一、这次要验证什么

最关键的假设：父母愿意、并且记得在吃完药后按"我吃好了"并发出确认。

其次：收到确认后，子女会不会真的少打"不放心"的电话；页面上的说明（第几格、长什么样、怎么吃）够不够让父母自己吃对。

二、事先定好的成功标准

测试前就定好，测完再对照，避免事后找理由。

标准为什么
父母本人确认率 ≥ 80%低于这个数，子女收到的"没确认"太多，产品会让人更焦虑
"吃了但没发确认" ≤ 2 次（3 天内）这是最伤信任的误报
"不放心"的例行电话 ≤ 1 次验证确认消息能不能替代例行电话
访谈里父母不觉得麻烦，子女觉得比平时更安心数字之外的真实感受

"我的记录"页会自动对照前三条。

三、准备（第 0 天，约 30 分钟）

  1. 先征得同意，可以这样说："我在做一个帮老人按时吃药的小产品，想请您帮我试 3 天。就是吃药的时候点开一个链接，吃完按一下，会给我发条短信。您吃什么药、怎么吃都不变，随时可以不试了。"
  2. 照原方案录入：打开 子女设置，按医生开的方案或药盒说明书填写，不改任何药和剂量。拿不准的地方先问医生或药师，不要猜。
  3. 发链接：把生成的链接发给长辈，帮她加到手机桌面或微信收藏，确保闹钟响了能一下点开。
  4. 设闹钟：按设置页列出的时间，在长辈手机上设好每天重复的闹钟（每顿两个：到点一次、15 分钟后一次）。
  5. 一起练一遍：陪长辈完整走一次：点开链接 → 听一遍 → 按"我吃好了" → 在短信里按发送。记下她第一次哪里犹豫。

如果长辈平时没有固定吃的药，可以用每天固定的维生素或"喝一杯水"代替，但要在结果里注明，这会降低结论的可信度。

四、测试期间每天的规则

时间谁做什么
到点长辈第 1 个闹钟响 → 点开链接 → 吃药 → 按"我吃好了" → 发短信
+15 分钟长辈第 2 个闹钟响（如果还没吃）
+30 分钟你还没收到短信 → 打电话。先问"刚才吃了吗"，不要直接说"你又忘了"
收到"记不清吃没吃"你马上打电话，请她看看药盒里这一格的药还在不在；不确定就不补吃，必要时问医生或药师
每顿结束你在 我的记录 里记结果、有没有打电话、她怎么说

不要额外提醒。测试期间除了上面的规则，尽量不要另外发消息提醒她吃药，否则测不出真实情况。

五、第 3 天的访谈（约 15 分钟）

问长辈：

  1. 这 3 天用下来，哪一步最麻烦？
  2. 有没有吃完了却忘了按的时候？当时在做什么？
  3. 页面上写的、读出来的，有没有看不清、听不懂的地方？
  4. 发短信这一步，您觉得怎么样？
  5. 您会不会觉得被"盯着"？
  6. 如果一直这样用，您愿意吗？想改成什么样？

问自己（子女）：

  1. 收到确认短信时，你真的放心了吗？还会想打电话吗？
  2. 没收到短信的时候，你第一反应是什么？
  3. 30 分钟这个时间是太长还是太短？
  4. 人工做的部分（看时间、打电话、记录）里，哪一步最想让产品自动做？

只记原话，不要引导。比如不要问"是不是很方便"，而是问"用下来感觉怎么样"。

六、测完之后

  1. 在"我的记录"里导出表格，对照成功标准。
  2. 把最重要的 3 句原话、1 个意外发现写下来。
  3. 决定下一步：达标 → 把人工部分做成自动（轻量版：父母一键确认、子女手机自动收到、超时自动提醒）；不达标 → 先改最卡的那一步再测，不急着加功能。

边界

本工具只按家人已有的用药方案做提醒和记录，不提供诊断、不推荐药物、不调整剂量。身体不适或怀疑吃错药，请联系医生；紧急情况拨打 120。父母的"确认"只代表本人确认，不能证明实际吞服。
