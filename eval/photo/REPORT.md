# 拍一拍核对 · 评测报告

- 模型：通义千问 qwen3-vl-plus（阿里云百炼，经 Cloudflare Worker 中转）
- 评测集：photo-v1，158 张仿真药盒图，14 类情况
- 结论：**误判「对了」0/107**，158 张全部答对；清晰正确药盒认对 16/16

## 1. 评什么

父母吃药前拍一下药盒：模型只抄药盒上的通用名、规格，并报告拿不准、药盒位置；规则拿这些和药品清单比对，给出五种答复之一。

| 指标 | 含义 | 要求 |
|---|---|---|
| 误判「对了」 | 照片里不是该吃的药，却答「对了」 | **必须为 0** |
| 清晰正确药盒认对率 | 第 1 类清晰照片答「对了」的比例 | 90% 以上 |
| 清晰照片「看不清」率 | 第 1 类清晰照片被答成「看不清」 | 越低越好 |
| 接口失败 | 重试一次后仍拿不到结果 | 记录，答复为「现在核对不了」 |

每张图标注了「可接受的答复」。例如模糊照片里的正确药盒，答「对了」或「看不清」都可接受；名字相近的药，只接受「不在清单」或「看不清」。

## 4. 三道护栏

**护栏 1：被挡住的字不许补。** 盒子是「盐酸二甲双胍缓释片」，「缓释」被手指挡住时，模型容易凭常识读成清单里的「盐酸二甲双胍片」。提示词要求被挡的字一个字写一个 □，并报告 sure；规则看到 □ 或 sure 不为 true，一律答「看不清」。「左旋」「肠溶」同理。

**护栏 2：药盒太小就请父母拿近再拍。** 远处的药盒规格那行只有几个像素高，模型会用常见规格补上，而且自称 sure。所以让模型报告药盒在照片里的位置，药盒最长边不到照片的 30%，规则就不看读到了什么，直接请父母「拿近一点再拍」。用一次重拍换掉一次可能的拿错药。

**护栏 3：输出格式兜底。** 模糊照片上模型偶尔多输出一个 `}`，Worker 针对这一种已知格式做修正，修不好按「现在核对不了」处理，不会误判。
