安心药箱：竞品、商业模式与 MVP 取舍

2026-10-22。外部数据都在文末列出来源；没有来源的判断都标为假设。

结论先说： ① 国外已有按月付费的服药提醒加照护者通知服务，说明"子女为父母的服药安心付费"这件事成立；国内联网药盒的问题是贵、复杂。 ② 安心药箱不做自动分药机，只把两件事做到最好：老人操作极简，以及子女看到的状态可信、不打扰。 ③ 第一版先不做硬件：用"父母手机 + 普通分格药盒"跑 2 周，验证"老人会不会确认""子女会不会少打电话"。数据达标后再上药箱硬件。 ④ 付费方是子女。验证期免费，之后按"低价药箱 + 子女端订阅"收费，具体价格等成本核算和付费意愿测试后再定。

一、市场背景

  • 老人多：2024 年我国 60 岁及以上人口约 3.1 亿，占总人口 22%（国家统计局数据，China Daily 报道）；2023 年底为 2.97 亿、21.1%（民政部统计公报）。
  • 慢病和多种药是常态：基于 CHARLS 2020 的研究显示，27 个省份 19,128 名 45 岁及以上中老年人中，慢性病患病率 80.9%，两种及以上慢病共存的比例 58.2%，高血压最常见（患病率 40.2%）。多种慢病往往意味着每天要吃多种药、分几个时间吃。
  • 没找到的数据：全国性的老人用药依从性数据、异地子女数量和他们的确认习惯，都没有找到可靠来源。这正是用户验证计划要补的。

二、竞品与替代方案

用户今天真正的选择不是"买哪个药盒"，而是"继续打电话，还是换一种方式"。所以把替代方案也一起比较。

方案价格好在哪不足
每天打电话 / 视频（现状）免费有温度，能顺便聊天每天打很累，难坚持；电话里说不清是哪种药、吃没吃对；父母可能报喜不报忧
手机闹钟 / 日历提醒免费零成本只提醒不反馈，子女看不到结果；老人关掉闹钟后就没有下一步
普通分格药盒几十元便宜，老人熟悉不提醒、不记录，装错也不知道
国内联网智能药盒报道中一款 3900 元有的支持定时提醒、记录上云、微信通知子女贵；有老人反映智慧养老产品"功能过于复杂"
Hero Health（美国，自动分药机）订阅：多年预付 $29.99/月起，月付 $44.99/月（12 个月承诺）自动按剂量出药，App 通知照护者价格高，需要长期合约；为美国医疗体系设计
MedMinder（美国，分格药盒）月租，各来源约 $40–125/月不等28 格药盒；闪灯 → 蜂鸣 → 短信逐级提醒，再通知照护者；有带锁型号价格不透明；提醒升级固定，家庭难以调整

从竞品里学到的三点：

  1. 付费意愿存在：Hero、MedMinder 都是按月收费的服务，核心卖点都是"照护者能知道"。这与安心药箱的子女端定位一致。
  2. 逐级提醒是行业共识：MedMinder 的"灯 → 声 → 短信 → 通知照护者"和我们的"响铃 → 15 分钟再响 → 30/60 分钟通知子女"思路一致；我们的差异是家庭可调，并且区分"没确认 / 打开过 / 设备离线"。
  3. 国内的空位在"便宜、简单"：国内已有联网药盒，但报道中的产品又贵又复杂。安心药箱不做自动分药、不接血压血糖设备，把成本和学习难度都压下来。

面试被问"为什么不直接打视频电话"：视频解决"想念"，安心药箱解决"确认"。正常日子里子女不用为确认吃药专门打电话，电话留给聊天和真正出问题的时候。产品不是替代电话，而是让电话不再是唯一的确认手段。

三、差异化定位

我们做我们不做
老人端：像来电一样的提醒、大字语音、一页一个决定、说一声就能确认自动分药机（成本高、维护难）
子女端：5 种可信状态、正常每晚汇总、异常按顺序升级给家人连接血压血糖等体征设备（功能变复杂）
装药引导 + 拍照核对 + 余量提醒诊断、用药建议、改剂量
AI 只做整理和转述（录入、指引朗读、周汇总文字）AI 判断"吃没吃"或决定何时通知

四、商业模式

谁付钱

子女。父母是使用者，但产品的价值（安心、少打电话）主要落在子女身上；子女也更习惯线上付费。假设：子女愿意为"不用天天打电话也放心"按月付费——这需要在验证期用付费意愿问题测试（见用户验证计划）。

四种收费方式比较

方式优点缺点判断
A. 硬件一次性买断用户好理解一次性收入，撑不起持续的通知、云服务和客服成本不单独用
B. 低价药箱 + 子女端订阅收入持续；硬件门槛低，降低首次购买阻力需要证明订阅值得续费推荐，作为正式收费方式
C. 纯软件订阅（只用手机）成本最低，适合验证期没有亮灯和开合信号，找药和误报问题解决不彻底用于 MVP 0 验证，先免费
D. 通过药房、社区卫生服务中心、养老机构或保险合作（B2B2C）获客成本可能更低，能触达不会主动搜索的家庭合作周期长，对数据合规要求更高验证成立后再探索

订阅里卖什么（假设，待验证）

  • 免费：到点提醒、父母确认、子女看到当天状态。
  • 订阅：异常按顺序升级给多位家人、装药拍照核对与余量提醒、"这一周的情况"汇总、方言播报。
  • 价格目标：药箱加首年服务的总价应明显低于报道中 3900 元的同类产品，具体数字等两件事做完再定：硬件物料成本核算、验证期的付费意愿测试。

项目怎么拿到数据
药箱硬件物料成本（亮灯、开合检测、联网模块、喇叭、电池）找 2–3 家方案商询价，按 1 千 / 1 万台分别报价

五、MVP 取舍：第一版先不做硬件

为什么：硬件研发周期长、成本高、改一次很慢。而产品成立的前提是两个行为假设——"老人会确认"和"子女会因此少打电话"——这两件事不需要硬件就能验证。先用最便宜的方式验证，再决定要不要投入硬件。

阶段做什么验证什么进入下一阶段的条件
MVP 0
2 周 · 3–5 个家庭		父母手机：来电式提醒、吃药指引、确认（按钮 + 语音）、求助。子女端：状态、通知规则、电话后处理。普通分格药盒贴上 1–4 号贴纸代替亮灯；装药后拍照发给子女，人工核对父母本人确认率；误报率；子女例行确认电话是否减少；子女是否愿意付费本人确认率 ≥ 80%，子女例行确认电话明显下降，且没有重复服药事件
MVP 1
小批量硬件		加药箱：药格亮灯、开合检测、联网；子女端增加"打开过药格"和"药箱离线"两种状态亮灯能否减少找药求助；开合信号能否把误报降下来误报率 < 20%，找药类求助明显减少
MVP 2
开始收费		订阅功能：多家人顺序通知、装药拍照 AI 比对、余量提醒、每周汇总、方言播报付费转化、续费率续费率达到预设目标后扩大渠道

如果 MVP 0 的确认率很低怎么办：先迭代确认方式（语音确认、简化按钮），而不是直接加硬件。如果最后发现"老人就是不爱确认，但会打开药格"，这正好成为上硬件、用开合检测兜底的证据。

不做硬件的代价和补救：

  • 没有亮灯，找药更难 → 药格贴大号数字贴纸，指引页写"贴着 1 号的那一格"。
  • 没有开合信号，无法区分"打开过"和"完全没动" → MVP 0 期间子女端只用 3 种状态（自己确认 / 电话确认 / 还没确认），并在访谈中记录误报的真实原因。
  • 没有设备离线问题，但有"父母手机静音或没电" → 提醒发不出时同样单独提示，不当成"没确认"。

六、主要风险

风险对策
老人不确认，误报多，子女反而更焦虑MVP 0 第一优先验证；确认方式多样化；误报率作为过程指标
健康数据合规父母本人单独同意；只采集必要信息；可随时退出和删除
产品被认为是医疗器械或给了医疗建议定位为家庭提醒与沟通工具；不诊断、不改药；补吃问题一律引导问医生或药师
大平台已有通用提醒功能通用提醒只解决"响"，不解决"确认可信"和"异常时谁来处理"；渠道上可考虑以小程序形态接入家庭已在用的平台（推测，需验证）
硬件售后（坏了、没电、断网）"药箱离线"状态 + 自动改用手机提醒兜底；MVP 1 小批量先测故障率
